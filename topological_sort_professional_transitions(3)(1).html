Introduction to Topological Sorting

Topological sorting is a linear ordering of the vertices of a Directed Acyclic Graph (DAG), where for every directed edge from vertex A to vertex B, A appears before B in the ordering.

It is used to schedule tasks, manage dependencies, and determine the correct order of activities, such as course prerequisites or software installation.

Algorithms Used in Topological Sorting

Kahn's Algorithm (BFS-based): Uses indegree to find vertices with no dependencies and processes them first. Removing each vertex updates its neighbors’ indegrees, and a short output signals a cycle.

DFS-based Approach: Uses Depth-First Search to explore vertices and adds them to the sorted order after visiting their neighbors. Reversing postorder produces the final order; a back edge signals a cycle.

Coding example

#include <stdio.h>

int main() {
    int n = 5;
    int graph[5][5] = {0};
    int indegree[5] = {0};
    int queue[5];
    int front = 0, rear = 0;
    int count = 0;
    int i, j, u;

    // Directed edges: A->B, A->C, B->D, C->D, D->E
    graph[0][1] = 1;
    graph[0][2] = 1;
    graph[1][3] = 1;
    graph[2][3] = 1;
    graph[3][4] = 1;

    // Calculate indegree of each vertex
    for (i = 0; i < n; i++) {
        for (j = 0; j < n; j++) {
            if (graph[i][j] == 1) {
                indegree[j]++;
            }
        }
    }

    // Add vertices with indegree 0 to the queue
    for (i = 0; i < n; i++) {
        if (indegree[i] == 0) {
            queue[rear] = i;
            rear++;
        }
    }
    printf("Topological Sorting: ");

    // Process the queue
    while (front < rear) {
        u = queue[front];
        front++;

        printf("%c ", u + 'A');
        count++;

        for (j = 0; j < n; j++) {
            if (graph[u][j] == 1) {
                indegree[j]--;

                if (indegree[j] == 0) {
                    queue[rear] = j;
                    rear++;
                }
            }
        }
    }

    if (count != n) {
        printf("\nCycle detected! Topological sorting is not possible.");
    }

    return 0;
}
